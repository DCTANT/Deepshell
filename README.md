# DeepShell

现代化 Web 终端工具：SpringBoot + Thymeleaf + ElementUI + xterm.js。

## 功能

- **连接管理**：主机/端口/用户名、密码或密钥认证、备注；**多级文件夹树**（新建/重命名/删除文件夹，删除后内容自动上移不丢数据；编辑连接时以级联选择器归入任意层级）；**置顶与收藏**（每个连接可独立设置，收藏支持筛选）；密码基于本机密钥 AES-GCM 加密存储
- **多标签终端**：WebSocket 实时流式传输、窗口尺寸自适应（PTY Resize）、连接状态指示、断线提示；标签右键支持**复制 IP / 查看服务器系统信息**（主机名、发行版、内核、CPU、内存、磁盘占用、IP、运行时长、负载、系统时间，经独立 exec 通道采集）；**刷新页面自动恢复已打开的会话标签并重连**
- **SFTP 文件管理**：目录浏览、上传、下载、新建目录、**新建文本文件（输入文件名后直接打开在线编辑）**、重命名、删除（目录递归）、小文件在线编辑保存、**拖拽移动文件到文件夹**（拖动到表格边缘自动滚动、移动前弹出确认对话框明确"文件→目录"）；**目录跟随终端**——终端里 `cd` 后文件面板自动切到对应目录（工具栏链接图标可开关）；**系统文件可直接拖进浏览器窗口上传**到当前目录（拖入时显示目标目录，成功后弹提示）；SFTP 工具栏另有返回上一目录（访问路径栈）、刷新与分析磁盘占用
- **快捷命令**：常用命令沉淀为片段，在工作台点击即执行（或仅填入待编辑）；面板顶部可选择**发送到当前会话 / 所有会话 / 勾选指定会话**（批量下发用）；每个命令可直接**编辑 / 删除**（工作台内点铅笔图标）
- **AI 生成命令**：终端底部命令栏点击魔法棒图标展开 AI 输入条，用自然语言描述需求（如"查看磁盘占用最大的前 10 个目录"），经 OpenAI 兼容接口自动翻译为 shell 命令并填入命令框待确认执行；在右上角菜单「AI 设置」中选择厂商（内置 DeepSeek / 通义千问 Qwen / 智谱 GLM / MiniMax / Kimi / OpenAI，也可自定义兼容地址），**模型列表由厂商接口实时获取**（一键刷新），从下拉直接选择而无需手填；API Key / 接口地址 / 模型均在此配置
- **AI 终端**（右侧面板第一个标签）：对话式 AI 运维——用自然语言描述需求（如"找出访问日志里请求最多的 IP"），AI 以当前会话的**登录用户身份**在服务器上自动执行命令、读取输出并逐步推进，直到任务完成；命令与输出以卡片展示在对话里（含退出码、可复制命令），经**独立 exec 通道**执行，不干扰正在操作的终端，AI 的 cd 目录会被自动跟踪；默认「**自动执行**」——删除 / 格式化 / 重启等**高风险命令会先暂停**等用户确认（面板内可切换「每步确认」）；**对话记录支持多对话并保存在 SQLite 数据库**（随数据目录一起迁移 / 备份）——面板左侧对话列表可新建 / 切换 / 删除，每个连接各自独立、每个对话有独立上下文与工作目录；**AI 回复经 SSE 流式返回、打字机式逐字显示**（生成中带闪烁光标，解析完成的命令仍以卡片展示）；单条命令最长 120 秒、超长输出自动截断
- **AI 可视化桌面**：AI 终端工具栏「AI 可视化桌面」按钮——以 Windows 资源管理器式全屏页面浏览 AI 当前工作目录（AI 尚未切换目录时回退到终端 / SFTP 当前目录）；支持大 / 中 / 小图标与详细列表四种视图、面包屑路径、快速访问侧栏、搜索筛选与排序；右键菜单可打开 / 在线编辑 / VSCode 编辑 / 下载 / 重命名 / 删除 / 复制路径 / 查看属性 / 压缩 / 新建文件夹 / 新建文件 / 上传 / 在终端中打开；**压缩子菜单**参考 7-Zip，支持 ZIP / 7Z / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ，可选择压缩级别、输出文件名和覆盖策略，调用服务器自带的 zip / tar / gzip / bzip2 / xz / 7z 命令；支持 Ctrl / Shift 多选、把文件拖到文件夹完成移动、把系统文件直接拖入当前目录或文件夹上传；**大 / 中图标视图会直接显示图片缩略图**，**双击图片打开全屏预览**（滚轮缩放、放大后拖动、旋转、适应窗口、上一张 / 下一张、下载，Esc 关闭），右键图片也有「预览」入口；缩略图懒加载、按修改时间缓存，超过 30MB 的图片不自动拉取；文件操作全部复用现有 SFTP 通道。页面底部带 **Windows 风格任务栏**：开始按钮、搜索框、AI 终端 / SFTP / 进程 / 磁盘快捷按钮、CPU / 内存 / 网络 / 连接状态托盘、时钟与返回工作台；**开始菜单**提供连接信息、固定应用、常用位置，并支持应用 / 当前目录即时搜索 + 回车在当前目录 6 层子目录中递归搜索文件（结果可直接定位或打开，最多 100 项）；开始菜单「设置」打开 **控制面板式设置窗口**，可调整默认文件视图、图片缩略图、隐藏文件、终端字体与背景、快捷键、时间显示（24 小时制 / 秒 / 日期 / 时区）与电源休眠（空闲自动返回工作台、重新连接 / 断开当前会话），并查看 / 配置 AI、局域网和当前连接信息
- **服务器监控**：工作台顶栏实时显示远端 CPU / 内存利用率（阈值变色进度条）与网络上下行速率；每 3 秒经独立 exec 通道采样 `/proc`，不占用交互终端；仅支持 Linux 服务器（Windows 目标会自动提示"监控不可用"）
- **进程管理**：类任务管理器面板——进程列表（名称/PID/用户/CPU/内存/状态/运行时长），瞬时 CPU 用 `/proc` 两次快照差分计算（与任务管理器同原理，而非 `ps` 的生命周期均值），支持排序、关键字过滤、3 秒自动刷新，以及结束（SIGTERM）/强杀（SIGKILL）进程；**单击进程行弹出详情**（PID/父进程/用户/状态/CPU/内存/运行时长/完整命令行，命令行可一键复制）
- **常用目录**：右侧面板「常用目录」标签——把常用路径存成快捷入口（浏览到目标目录点「定位」一键添加，或直接输入路径），**点击条目即在终端执行 cd**（路径含特殊字符时自动安全转义），文件面板同步进入该目录；悬浮条目可移除
- **磁盘分析**（WizTree 式）：右侧面板「磁盘」标签——对指定目录执行 `du` 列出每个子目录 / 文件的大小与占比（按大小降序、占比条展示），**点击文件夹逐层下钻**定位最占空间的目录，「↑」返回上级；SFTP 工具栏可一键「分析当前目录」直达；不跨文件系统挂载点统计

- **登录认证（可选）**：`application.yml` 中开启后，访问工作台与 API 需先登录；账号密码可配置（默认 `admin` / `deepshell`），JWT 以 HttpOnly Cookie 保存，默认 6 小时过期；右上角菜单「登录与安全」可调整 Token 有效期，页面持续使用时会自动续期。默认关闭，本机使用无需登录
- **工作台菜单**（右上角汉堡按钮）：连接导入（支持一次框选多个文件，可导入 FinalShell 连接文件）/ 连接导出（弹窗勾选要导出的连接）、终端字体设置（即时生效并记忆）、快捷键设置（双击 Ctrl / Tab 补全 / Esc 关闭可开关）、背景图片设置（本地上传或 URL，透明度与模糊可调；终端背景自动透明透出）、**AI 设置**（DeepSeek / 通义千问 / 智谱 GLM / MiniMax / Kimi / OpenAI 等厂商，兼容任意 OpenAI 接口，模型列表实时获取、下拉选择，用于命令翻译与 AI 终端）、**局域网访问开关**（默认仅本机 127.0.0.1，开放并重启后局域网可访问，弹窗内提供访问地址复制与安全提示）

> 按需精简：不含多用户注册、配置云端同步、端口转发等非核心功能；单账号登录可在配置中按需开启。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Spring Boot 2.7.18（Java 8）、Spring WebSocket、Spring Data JPA、SQLite（xerial sqlite-jdbc，单文件零依赖）、JSch（mwiede 维护分支） |

## 快速开始

前置要求：JDK 8+、Maven。

```bash
# 构建（同时生成分发包 target/deepshell-1.0.0.zip）
mvn -DskipTests package

# 或直接运行 jar（开发调试）
java -jar target/deepshell.jar
```

### 分发包（推荐）

解压 `target/deepshell-1.0.0.zip` 后的目录结构：

```
deepshell-1.0.0/
├─ deepshell.jar      主程序
├─ application.yml    外置配置（可改端口 / 数据目录等，覆盖内置默认值）
├─ start.cmd          Windows 启动脚本（双击运行，关闭窗口即停止）
├─ start.sh           Linux 启动脚本（后台运行）
├─ stop.sh            Linux 停止脚本
└─ data/              运行数据（数据库 / 密钥 / 配置 / 日志 / 背景图）
```

- **Windows**：双击 `start.cmd`
- **Linux**：`./start.sh` 启动 / `./stop.sh` 停止（控制台输出见 `data/logs/console.log`）
- 启动完成后会自动打开默认浏览器；不需要时在外置 `application.yml` 设 `deepshell.open-browser: false`（或启动命令加 `-Ddeepshell.open-browser=false`）

开发模式（在 IntelliJ IDEA 中运行 `DeepShellApplication`）数据目录默认为 `~/.deepshell`；分发包数据全部位于程序目录 `data/` 下，拷贝整个目录即可迁移。

启动后访问 **http://localhost:18080**

## 使用说明

1. 打开页面即是**工作台**（首页）：点标签栏「＋」或空状态「打开连接」弹出连接列表 → 可直接「新建连接」（密码认证直接填密码；密钥认证填**运行本工具的机器上**的私钥文件绝对路径，如 `C:\Users\you\.ssh\id_rsa`）；列表内可新建文件夹、编辑（含「所属文件夹」归入层级）、**删除连接**、拖拽连接入文件夹；**文件夹上右键「连接所有」**可批量打开该文件夹（含子文件夹）中的全部服务器
2. 点击「连接」进入工作台，终端自动打开并登录；工作台标签栏「+」或空状态「打开连接」弹出**树形连接列表**（顶部「最近连接」区最多显示 5 个最近打开的连接，支持搜索、收藏筛选、置顶区；每个连接右侧 ⚙ 可快捷置顶 / 收藏 / 编辑连接；连接可直接**拖到文件夹上**归入文件夹）
3. 工作台右侧面板：
   - **AI 终端**：输入需求回车，AI 自动执行命令并回传结果，直到完成；高风险命令会先暂停等确认（详细见上方功能说明）
   - **文件 SFTP**：双击目录进入 / 双击文件在线编辑；顶部支持路径直达、上传、新建文件夹
   - **快捷命令**：点击 = 执行（自动追加回车）；点右侧 `+` = 仅填入终端，人工确认后回车
4. 顶部标签可开多个会话；中键或 × 关闭标签（会断开对应 SSH 连接）

## 数据与安全

| 数据 | 位置（数据目录下） |
|---|---|
| 连接/快捷命令数据 | `db/deepshell.db`（SQLite 单文件库） |
| 密码加密密钥 | `secret.key`（首次启动自动生成） |
| 登录签名密钥 | `auth.key`（首次启动自动生成；删除后所有登录 Token 失效） |
| 登录 Token 有效期 | `auth.properties`（在右上角「登录与安全」中修改后写入） |
| AI 接口配置 | `ai.properties`（厂商 / API 地址 / Key / 模型） |
| 背景图片 | `bg/` |
| VSCode 编辑副本 | `edit/` |
| 运行日志 | `logs/` |

> 数据目录：分发包默认为程序目录下的 `data/`（可在同级 `application.yml` 中修改）；开发模式为 `~/.deepshell`。拷贝该目录即可迁移全部数据（含密钥与数据库）。

- 密码/私钥口令经 AES-GCM 加密后落库，明文仅在提交与建立连接时短暂存在于内存
- 本工具设计为**本机使用**；请勿直接暴露到公网（SSH 连接代理无鉴权）

## 常用配置（application.yml）

内置默认配置在 `src/main/resources/application.yml`；分发包使用与 jar 同级的外置 `application.yml`，只需填写要覆盖的项：

```yaml
server.port: 18080             # 服务端口（默认 18080）
deepshell.data-dir: ./data     # 数据目录（默认 ~/.deepshell；分发包为 ./data）
deepshell.open-browser: true   # 启动后自动打开浏览器

# 登录认证（默认关闭；开启后必须登录才能访问工作台）
deepshell.auth.enabled: false
deepshell.auth.username: admin
deepshell.auth.password: deepshell
deepshell.auth.token-expire-hours: 6
```

> 登录账号密码在配置文件中为明文，请务必修改默认密码；开启登录后建议不要将服务直接暴露到公网。Token 有效期还可在右上角菜单「登录与安全」中在线调整（1 - 720 小时），设置保存在数据目录的 `auth.properties` 中。
