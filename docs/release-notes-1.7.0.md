# DeepShell 1.7.0 更新日志

发布日期：2026-10-26

对比版本：v1.6.2

## 新增

### 内置 MCP 服务，AI 客户端可直接调用

- 内置 `/mcp` 接口，支持 MCP Streamable HTTP 与 stdio 桥接，兼容 `2024-11-05`、`2025-03-26`、`2025-06-18` 协议版本。
- Qoder、Cursor、Claude Code、Claude Desktop 等 AI 客户端可以列出已保存连接、建立 SSH 会话、执行命令、通过 SFTP 读写 / 上传 / 下载文件、查看系统信息与进程、打开连接标签。
- MCP Token 与集成接口 Token 相互独立，可在「安全与访问 → MCP 服务」中查看、复制或重新生成；重新生成后旧配置立即失效。
- 所有 MCP 工具调用写入审计日志，命令执行、文件写入 / 上传 / 下载另有独立审计记录。
- 不提供删除连接、修改连接凭据等高危管理能力，连接与密码仍只在 DeepShell 界面中维护。

### AI 设置新增 Token 使用统计

- 自动记录每次模型调用的输入 token、输出 token、合计与调用次数。
- AI 设置中展示**今天、近 7 天、近 30 天、累计**四档用量，桌面端和手机端均可查看。
- 统计覆盖 AI 终端对话、命令翻译、对话标题、上下文压缩以及模型输出不合规时的自动重试。
- 接口未返回 usage 时按字符数估算，并在统计中标注估算次数；统计只保存在本机，不记录对话内容。

## 优化

- AI 设置弹窗改为 700px 紧凑布局，压缩说明文字和统计卡片高度，常见窗口高度下不再出现滚动条。
- 修复「上下文窗口」标签在窄弹窗中换行的问题。
- 模型列表获取失败提示限制为两行，完整错误信息可悬停查看，避免长错误撑高弹窗。
- 桌面「设置 → 系统信息」中的桌面 / 开始菜单快捷方式、开机启动、托盘图标、自动更新、检查更新等控件适配深色主题。
- 设置项中的普通按钮随窗口明暗自动切换，深色窗口下不再出现突兀的浅色按钮。

## 修复

- 修复深色桌面设置中部分卡片、按钮和开关仍使用浅色样式的问题。

## 升级说明

- Windows 绿色版：下载 `deepshell-1.7.0-windows-x64-portable.zip`，可同时下载同名 `.sha256` 校验文件；解压后双击 `DeepShell.exe`。
- 传统分发包：下载 `deepshell-1.7.0.zip`，需要本机安装 JDK 8+；Windows 双击 `start.cmd`，Linux 执行 `./start.sh`。
- 应用内自动更新只接受带 `.sha256` 的绿色版 ZIP；升级会保留 `data/` 目录与 `application.yml`，不会影响连接、密码和 AI 配置。
