# DeepShell 1.9.0 更新日志

发布日期：2026-10-31

对比版本：v1.8.0

## 新增

### DeepShell 执行网关（跨网络 SSH 出口）

- 工作台菜单新增「执行网关」，提供「使用网关（本机出口）」与「作为网关（提供服务）」两种角色。
- 使用网关：可保存多个网关（名称、地址、Token、是否跳过自签证书校验、启用状态），支持测试、编辑、删除；新建 / 编辑连接时可选择「执行网关」，终端、SFTP、系统监控、端口转发等全部 SSH 能力复用原有链路，因为 SSH 协议端到端到目标机。
- 作为网关：一键启用并生成 Token，可复制或重新生成，也可在 `application.yml` 中固定；目标白名单支持精确主机、`*.域名`、IP 与 CIDR，留空会拒绝全部目标；并发隧道上限 1 - 64（默认 16），界面实时显示当前隧道数。
- 安全：网关只负责 TCP 拨号与转发，不改写 SSH 内容，目标机凭据仍只保存在发起端；网关侧校验 Token、拒绝浏览器 Origin 调用，并按白名单与并发上限限制隧道；网关设置与 Token 操作写入审计日志。
- 适用场景：本机无法直连目标网段，但另一台 DeepShell 能访问目标机（机房出口 / 跳板）。网关地址支持带路径前缀，便于经反向代理访问。

### 官方插件在线安装与独立插件仓库

- 主程序不再内置官方插件 ZIP，安装包体积减少约 18MB；官方插件统一在独立 Gitee 仓库维护，主程序通过 `catalog.json` 在线获取插件版本、下载地址与 SHA-256。
- 桌面「安装 / 管理」中的官方插件列表支持在线安装与更新：下载后校验 SHA-256 与官方 RSA 签名；目录缓存 10 分钟，网络异常时回退上次缓存；单个插件下载限制 50MB；加载失败可重试；仍支持手动导入 ZIP。
- 官方插件 ID 统一迁移到 `com.itdct.deepshell.plugin.*`，旧 ID 保留为官方保留 ID；升级时自动迁移 `plugin-data` 中的连接配置并清理旧插件目录，不需要重新填写连接密码。
- 含后端 JAR 的插件安装或更新后仍显示「待重启」，重启 DeepShell 后加载新模块。

### 文本编辑器外观

- 文本编辑器「视图 → 外观风格」新增 **浅色 / 深色 / 跟随桌面** 三档；选择立即生效并记住，桌面文本编辑器窗口与工作台 SFTP 在线编辑弹窗共用同一设置。
- 「跟随桌面」根据 AI 桌面窗口颜色自动切换；深色模式下菜单、下拉、行号与语法高亮同步适配。

### 可视化桌面全屏

- 桌面任务栏新增全屏按钮，支持 `Alt+Enter` 切换全屏。
- Electron 桌面版支持 `F11`：由主进程接管并切换原生窗口全屏，解决应用移除原生菜单后无法用 F11 全屏的问题；浏览器版继续使用 Fullscreen API。

## 修复

- 修复桌面多选文件时「下载」子菜单可能被「跨服务器传输」占用而无法显示的问题。

## 构建与开发

- 新增 Electron 桌面版一键打包脚本 `tools/build-electron.ps1`：打包 Electron 壳、精简 JRE 与 `deepshell.jar`，输出 ZIP 与 `.sha256` 到 `electron/out/`。
- 官方插件源码与构建流程迁移至独立仓库 [deepshell-plugin](https://gitee.com/decentant/deepshell-plugin)，发布插件不再需要重新发布 DeepShell 安装包。

## 升级说明

- Windows 绿色版：本次恢复为单个 `deepshell-1.9.0-windows-x64-portable.zip`（约 97MB，低于 Gitee 单附件 100MB 限制），请连同同名 `.sha256` 一起下载；解压后双击 `DeepShell.exe`，无需安装 JDK。应用内自动更新恢复可用。
- 传统分发包：下载 `deepshell-1.9.0.zip`，需要本机安装 JDK 8+；Windows 双击 `start.cmd`，Linux 执行 `./start.sh`。
- 从 1.8.0 升级：覆盖程序目录即可，请保留 `data/` 目录与 `application.yml`；连接、密码、插件、AI 配置和桌面布局不受影响。使用 1.8.0 分卷绿色版的用户，本次可直接下载 1.9.0 单 ZIP 覆盖升级，之后自动更新恢复。
- 官方插件已迁移到新 ID，首次升级后会自动迁移插件数据；含后端的插件需要重启 DeepShell。
- 执行网关默认关闭；作为网关提供服务时，请务必配置目标白名单并妥善保管 Token。
