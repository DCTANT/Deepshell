连接与工作台
  • 右上角「＋」打开已保存连接，或点击「新建连接」直接创建后立即连接；新建连接默认是首次连接向导：选云厂商与系统镜像、按提示找 IP / 安全组 / 默认登录名，填写后用「测试并保存」。连接右侧 ⚙ 可设置置顶 / 收藏 / 编辑连接，也可以把连接拖动到文件夹上快速归入文件夹；文件夹上右键「连接所有」可批量打开其中（含子文件夹）的全部服务器
  • 连不上时：测试连接或终端连接失败会按错误类型给步骤（端口拒绝、超时、DNS、安全组、用户名 / 密码、私钥格式、代理 / 跳板机等）；首次连接或指纹变化时会用「服务器身份证」解释 SHA256 主机指纹，并给出在服务器上核对的命令。请先核对再信任，无法确认时不要更新指纹
  • 直接进入桌面（无需服务器）：工作台空状态或「打开连接」弹窗底部点「直接进入桌面」，会打开 DeepShell 本机的本地桌面，不建立 SSH 连接。文件保存在数据目录的 Desktop 子目录（可通过桌面任务栏「本地桌面」提示查看），支持资源管理器浏览、新建 / 上传 / 下载 / 重命名 / 删除 / 在线编辑、图片与视频预览以及桌面插件；「终端」直接打开本机 Shell（Windows cmd / Unix $SHELL），无需 SSH 回本机；AI 终端、任务管理器、服务、网络工具、磁盘、常用目录、快捷键命令、服务器搜索等依赖服务器的功能会自动隐藏并禁用。除首次进入外，也可在连接管理窗口点「本地桌面」在新标签页打开；地址带 local=1 时刷新会回到本地桌面
  • 页面刷新（F5）后会自动恢复之前打开的会话标签并重新连接，不会丢失工作现场
  • 标签：拖动可排序；右键支持复制 IP / 系统信息 / 重新连接 / 断开 / 关闭（其他、左边、右边、全部）；中键点击快速关闭
  • 终端分屏：工具栏「左右分屏 / 上下分屏」按钮是追加窗格，已有 2 个窗格时再点可增加第 3 个；已有左右分屏后上下分屏按钮禁用，反之亦然。优先复用当前连接已有标签，没有时新开同连接会话；拖动分隔条可调整窗格宽/高；每个窗格右上角 × 关闭该分屏并弹出确认，只剩一个窗格时自动退出分屏。分屏顺序、尺寸和焦点在刷新页面后恢复；手机版不支持分屏
  • 命令审计：终端里手动提交的命令会写入「审计日志」和 logs/terminal-commands.log，记录连接、用户、来源 IP 与命令；命令底栏、快捷命令与本地 Shell 命令同样记录，密码 / SSH 确认等交互提示自动跳过。历史命令调出后提交也能被识别
  • 终端顶栏实时显示远端 CPU / 内存 / 交换 / 网络利用率，悬浮查看主机、负载与运行时长
外部调用（跳板机客户端）
  • 使用分发包（java -jar）启动后会自动把 deepshell:// 注册为当前用户的 URL 协议：Windows 写入 HKCU 注册表、无需管理员权限，Linux 写入 xdg desktop 文件；IDE / classes 模式不注册。可在右上角菜单「安全与访问 → 外部调用」查看状态或重新注册
  • 网页 / 门户里的 <a href="deepshell://connect?id=12">打开服务器</a> 点击后由系统拉起本机 DeepShell：已运行时交给现有实例打开新标签页，未运行时自动启动；无需浏览器插件
  • 按主机直连可传 host / port / username / password（或 authType=KEY&keyPath=...）/ name / source；本机已有相同主机、端口与用户名的连接会复用已保存凭据，否则新建并保存连接。建议优先用 id 或省略密码，避免密码出现在链接里
  • 外部调用接口只接受本机回环请求并校验数据目录中的 protocol.key，但网页仍可触发打开已保存连接；请开启登录，不要把带密码的链接放到公开页面

  • 右上角菜单「安全与访问 → MCP 服务」可查看 MCP 地址与 Token，并复制 HTTP / stdio 接入配置；AI 客户端可通过 MCP 直接列连接、执行命令、读写文件、查看监控，每次调用都会写入审计日志
  • JumpServer / 门户后端向 POST /api/integration/connections/open 发送 JSON，并在请求头携带 X-DeepShell-Integration-Token（或 Bearer Token）。接口按 host + port + username 更新已有连接，匹配不到时新建连接，然后通知已打开的 DeepShell 页面自动打开连接标签

  • 上下文用量：输入框下方显示当前上下文占用与窗口比例，点击可查看上次请求的真实 Prompt / 输出 / 前缀缓存命中；超过 80% 会提示压缩。上下文使用超过 50% 后，工具栏压缩图标与上下文卡片中的「压缩上下文」按钮才可用；厂商未返回 usage 时自动按字符估算
  • 压缩上下文：点击工具栏压缩图标、上下文卡片中的「压缩上下文」或输入 /compact，把较早对话生成结构化摘要并替换旧消息，保留最近消息；压缩卡片可展开查看摘要，摘要会作为后续请求的背景
  • 置顶与分叉：对话列表顶部按钮可置顶当前对话（置顶优先展示且不会被数量上限淘汰）；工具栏「分叉」会复制当前对话为新对话，AI 回复或命令结果下方的「分叉」可从该条消息处复制分支，原对话保持不变
  • 输出：回复支持 Markdown（列表 / 加粗 / 行内代码 / 代码块）；模型返回思考过程时显示可折叠的「思考过程」；长命令输出可展开全部或复制；请求失败可一键重试，达到单轮步数上限可一键继续
  • 单轮步数：默认 50 步，可在右上角菜单「AI 设置」中调整为 1-100；达到上限会暂停并给出「继续执行」按钮，不会无限执行消耗额度
  • 命令走独立通道执行，不干扰（也不显示在）你正在操作的终端；AI 会记住自己 cd 到的目录，但 export 的环境变量不保留
  • 默认「自动执行」：AI 连续执行多步，命令会直接执行；切到「每步确认」则每条命令都需你点执行
  • 命令必须是非交互的：不能执行 vi / top 这类需要人工输入的程序；sudo 若无免密会失败；单条命令最长 120 秒，输出过长自动截断
  • AI 可视化桌面：点工具栏「AI 可视化桌面」进入资源管理器式全屏页面，从 AI 当前工作目录开始；支持大 / 中 / 小图标与详细列表、面包屑、快速访问、搜索排序；右键菜单可编辑 / 下载（多选可打包成 ZIP——后端通过 SFTP 流式打包，或逐个下载；本机访问时可下载到本机目录）/ 重命名 / 删除 / 新建 / 上传 / 查看属性 / 压缩；压缩子菜单支持 ZIP / 7Z / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ，可选压缩级别、文件名和覆盖策略，调用服务器自带压缩命令；对 ZIP / JAR / WAR / TAR / TAR.GZ / TGZ / TAR.BZ2 / TAR.XZ / 7Z / RAR / GZ / BZ2 / XZ 压缩包，右键「解压」可解压到当前目录或同名文件夹，默认跳过已存在的同名文件，调用服务器自带 unzip / tar / 7z / unrar / gzip / bzip2 / xz；支持 Ctrl / Shift 多选、在空白处按住左键拖动框选（Ctrl 追加、拖到边缘自动滚动）、拖动文件到文件夹移动、从桌面图标拖到资源管理器窗口（松手后选择复制或剪切）、系统文件拖入上传；工具栏与鼠标侧键 / Alt+← →支持目录后退、前进；大 / 中图标视图会显示图片与视频缩略图：图片由服务端降采样，视频由浏览器读取视频流抓取首帧并叠加播放角标（只加载可见项、限并发，超大或编码不支持的视频回退为文件图标），双击图片在新标签页打开预览，支持缩放、拖动、旋转和上一张 / 下一张；双击视频也会在新标签页打开播放器，支持进度拖动 / 快进快退 / 同目录视频切换，关闭标签页即回到原目录；双击文本文件会打开「文本编辑器」应用窗口，顶部含文件 / 编辑 / 选择 / 视图 / 帮助菜单，支持多标签、新建 / 打开 / 保存 / 另存为，关闭标签前会提示未保存修改；工具栏新增「过滤」开关，勾选后只显示包含关键词的行（支持区分大小写与正则），过滤视图为只读，关闭过滤后恢复编辑
  • 桌面应用插件：开始菜单「已安装应用 → 安装 / 管理」导入 ZIP（plugin.json + 入口 HTML + 图标），安装后直接出现在开始菜单；插件在隔离沙箱 iframe 中运行，支持同 ID 更新与卸载；格式详见 README「桌面应用插件」。官方 Redis 管理器 支持保存多个连接：连接成功后勾选「保存连接信息」，密码由 DeepShell 使用本机密钥加密保存在插件数据目录，不会回传给浏览器；下次在欢迎页或连接弹窗中选中已保存连接即可直接连接，也可编辑或删除

  • 服务与计划任务 / 网络工具箱 / 多机命令：开始菜单打开。服务窗口列出 systemd / SysV 服务，可启动、停止、重启与设置 / 取消开机自启；计划任务页查看用户 crontab（可添加 / 删除）、系统 crontab 与 systemd 定时器。网络工具箱的实时流量页采用与任务管理器一致的工具栏与表格样式，按程序显示实时上下行、累计流量与连接数，右键（或双击）程序行可复用任务管理器的进程详情浮层查看完整命令行 / CPU / 内存 / 运行时长，并可结束进程；非 root 登录时可点击工具栏「以 root 采样」，通过免密 sudo 或输入一次 sudo 密码（仅存于服务内存 30 分钟）读取全部进程，登录用户本身是 root 时直接显示 root 标识；端口与防火墙页展示 TCP / UDP 监听端口、进程、PID 与监听范围（所有网卡 / 仅本机 / 指定地址），读取 UFW / firewalld / nftables / iptables 状态和规则，支持筛选「只看所有网卡」与展开原始规则，普通用户可复用「以 root 读取」补全其他用户的进程名和防火墙规则；连通性测试支持 ping / 路由追踪 / DNS 查询 / 端口探测。多机命令可选择多台已保存连接并发执行同一条命令，逐台查看退出码、耗时与输出；已打开的会话直接复用，未连接的按保存的代理 / 跳板机配置临时建连

常用目录（右侧面板）

  • 连接、密码（AES 加密）、快捷命令与背景图存放于数据目录（分发包为程序目录下 data/），拷贝该目录即可迁移
