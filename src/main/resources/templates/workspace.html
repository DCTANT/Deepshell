连接与工作台
  • 右上角「＋」打开已保存连接，或点击「新建连接」直接创建后立即连接；连接右侧 ⚙ 可设置置顶 / 收藏 / 编辑连接，也可以把连接拖动到文件夹上快速归入文件夹；文件夹上右键「连接所有」可批量打开其中（含子文件夹）的全部服务器
  • 页面刷新（F5）后会自动恢复之前打开的会话标签并重新连接，不会丢失工作现场
  • 标签：拖动可排序；右键支持复制 IP / 系统信息 / 重新连接 / 断开 / 关闭（其他、左边、右边、全部）；中键点击快速关闭
  • 终端顶栏实时显示远端 CPU / 内存 / 交换 / 网络利用率，悬浮查看主机、负载与运行时长
命令输入栏（终端底部）
  • 双击 Ctrl 显示 / 隐藏；Esc 关闭；Enter 发送
  • Tab 智能补全（路径 / 历史 / 快捷命令）；Alt 或 ↑↓ 调出历史命令
  • AI 生成命令：点击魔法棒图标展开 AI 输入框，用自然语言描述需求，自动翻译为 shell 命令并填入命令框（需先在右上角菜单「AI 设置」配置 API Key）
  • 右侧工具：历史、选项（发送后清空 / 追加回车 / 忽略空行）、多会话下发（一条命令同时发到多台）、复制 / 粘贴、搜索、连接编辑、全屏
AI 终端（右侧面板）
  • 用自然语言描述需求，AI 会以当前会话的登录用户身份在服务器上自动执行命令、读取输出并逐步推进，直到任务完成；命令与输出以卡片形式展示（含退出码、耗时，可复制命令 / 输出）
  • 输入：Enter 发送、Shift+Enter 换行；↑↓ 调出历史输入；输入 / 打开快捷命令（/new、/clear、/auto、/manual、/desktop、/stop、/help）；AI 执行中按 Enter 会把新要求排队，本轮结束后自动发送；中文输入法回车不会误触发送
  • 输出：回复支持 Markdown（列表 / 加粗 / 行内代码 / 代码块）；模型返回思考过程时显示可折叠的「思考过程」；长命令输出可展开全部或复制；请求失败可一键重试，达到单轮步数上限可一键继续
  • 单轮步数：默认 30 步，可在右上角菜单「AI 设置」中调整为 1-100；达到上限会暂停并给出「继续执行」按钮，不会无限执行消耗额度
  • 命令走独立通道执行，不干扰（也不显示在）你正在操作的终端；AI 会记住自己 cd 到的目录，但 export 的环境变量不保留
  • 默认「自动执行」：AI 连续执行多步；遇到删除 / 格式化 / 重启等高风险命令会先暂停，在你点击「执行 / 跳过」后继续。切到「每步确认」则每条命令都需你点执行
  • 命令必须是非交互的：不能执行 vi / top 这类需要人工输入的程序；sudo 若无免密会失败；单条命令最长 120 秒，输出过长自动截断
  • AI 可视化桌面：点工具栏「AI 可视化桌面」进入资源管理器式全屏页面，从 AI 当前工作目录开始；支持大 / 中 / 小图标与详细列表、面包屑、快速访问、搜索排序；右键菜单可编辑 / 下载（多选可打包成 ZIP——后端通过 SFTP 流式打包，或逐个下载；本机访问时可下载到本机目录）/ 重命名 / 删除 / 新建 / 上传 / 查看属性 / 压缩；压缩子菜单支持 ZIP / 7Z / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ，可选压缩级别、文件名和覆盖策略，调用服务器自带压缩命令；对 ZIP / JAR / WAR / TAR / TAR.GZ / TGZ / TAR.BZ2 / TAR.XZ / 7Z / RAR / GZ / BZ2 / XZ 压缩包，右键「解压」可解压到当前目录或同名文件夹，默认跳过已存在的同名文件，调用服务器自带 unzip / tar / 7z / unrar / gzip / bzip2 / xz；支持 Ctrl / Shift 多选、在空白处按住左键拖动框选（Ctrl 追加、拖到边缘自动滚动）、拖动文件到文件夹移动、从桌面图标拖到资源管理器窗口（松手后选择复制或剪切）、系统文件拖入上传；工具栏与鼠标侧键 / Alt+← →支持目录后退、前进；大 / 中图标视图会显示服务端降采样后的图片缩略图（只加载可见项、限并发，避免大量原图卡死页面），双击图片在新标签页打开预览，支持缩放、拖动、旋转和上一张 / 下一张；双击视频也会在新标签页打开播放器，支持进度拖动 / 快进快退 / 同目录视频切换，关闭标签页即回到原目录；双击文本文件会打开「文本编辑器」应用窗口，顶部含文件 / 编辑 / 选择 / 视图 / 帮助菜单，支持多标签、新建 / 打开 / 保存 / 另存为，关闭标签前会提示未保存修改；工具栏新增「过滤」开关，勾选后只显示包含关键词的行（支持区分大小写与正则），过滤视图为只读，关闭过滤后恢复编辑

  • 常用目录 / 快捷命令（桌面窗口）：常用目录可添加、移除目录，单击目录会在终端执行 cd 并让资源管理器跳转到该目录；快捷命令固定发送到当前桌面会话，单击执行、右侧 + 仅填入输入框；桌面终端窗口底栏也提供快捷命令入口，工作台的快捷命令面板保持不变
  • 连接管理（桌面窗口）：开始菜单「连接管理」在桌面内以窗口打开，支持搜索、收藏 / 置顶、文件夹分组、拖动排序、连接导入导出以及新建 / 编辑 / 复制 / 删除；单击连接会在新浏览器标签页打开该连接的 AI 桌面，当前桌面保持不变。终端工作台的「打开连接」弹窗行为不变
  • 电源菜单：开始菜单底部「返回工作台」右侧的电源按钮，点开提供关机 / 重启 / 断开连接——关机和重启会真实操作远端服务器（执行 shutdown，需当前用户为 root 或已配置免密 sudo，否则会提示失败并说明原因）；关机后会主动断开当前会话、不再自动重连，重启后会按退避策略自动重连，也可在任务栏连接状态处右键手动重新连接；操作会先弹出危险确认，并记入审计日志
  • 设置（控制面板）：开始菜单「设置」打开控制面板式窗口，左侧分类包含外观与桌面、时间与时钟、快捷键、电源与休眠、AI 助手、网络与连接、系统信息；可切换默认视图、图片缩略图、隐藏文件、终端字体 / 背景、快捷键、24 小时制 / 秒 / 日期与时区显示，设置空闲自动返回工作台，或重新连接 / 断开当前 SSH 会话
  • 多对话：面板左侧是对话列表（最近使用的在前），点「新对话」开新会话，点条目切换；每个对话有独立上下文与工作目录，鼠标悬浮条目可删除；记录保存在服务端 SQLite 数据库（随数据目录迁移 / 备份），刷新、换浏览器打开都还在（浏览器里旧存的记录首次打开自动迁移入库）
文件 SFTP（右侧面板）
  • 双击目录进入 / 双击文件在线编辑；点击列头排序（名称 / 大小 / 修改时间）
  • 在线编辑使用 CodeMirror：行号、语法高亮、区分大小写 / 全词 / 正则查找、替换与全部替换、匹配项高亮、双击选中词高亮；快捷键 Ctrl+F 查找、Ctrl+H 替换、Ctrl+S 保存。终端工作台的 SFTP 面板仍以**弹窗**打开，但内部与 AI 桌面的「文本编辑器」应用窗口使用同一套顶部菜单（文件 / 编辑 / 选择 / 视图 / 帮助）、多标签、新建、打开远程文件、保存、另存为、撤销 / 重做、剪切 / 复制 / 粘贴、转到行、行号 / 自动换行 / 字号缩放及未保存确认
  • 拖动文件名到文件夹即可移动（拖到表格边缘自动滚动找目标，移动前弹确认框）
  • VSCode 图标：下载到本机用 VSCode 打开，保存后自动同步回服务器（含 VSCode 原子保存，失败会自动重试）
  • 批量分发：工具栏「批量分发」图标（分享）打开；选择本地多个文件、目标目录与多台已保存连接，服务端并行上传到每台服务器的同一路径；已打开的会话直接复用，未连接的自动建立临时 SFTP 连接；可查看逐台进度、取消与重试失败项
  • 工具栏：返回上一目录 / 上级目录 / 新建文件夹 / 新建文件（创建后直接打开编辑）/ 上传 / 刷新当前目录 / 分析磁盘占用 / 目录跟随开
  • 目录跟随（默认开启）：终端里 cd 到某个目录后，文件面板自动切换到该目录；手动浏览不受影响，直到下次 cd；点工具栏链接图标可开关
  • 把系统里的文件直接拖进浏览器窗口即可上传到当前目录（拖入时会显示目标目录提示，成功后顶部弹出提示）
  • 名称左侧复选框支持多选（表头可全选）；选中后出现操作条，可打包下载（后端通过 SFTP 流式打包，浏览器只下载一次）或逐个下载文件（文件夹会跳过）
  • 本机（127.0.0.1 / localhost）访问且运行环境有图形界面时，还可下载到本机：后端弹出原生目录选择框，自动创建 deepshell-目录名-时间 子目录，通过 SFTP 直接写盘；传输队列显示进度与当前文件，完成后可查看失败明细并在文件管理器中打开目录
  • 每行操作：下载、重命名、删除（目录递归删除，带确认）
常用目录（右侧面板）
  • 按当前主机（连接）分别保存，切换标签页自动切换对应的常用目录，不同主机互不影响
  • 把常用路径存成快捷入口：浏览到目标目录后点「定位」按钮一键添加，或直接输入路径
  • 点击条目即在终端执行 cd（特殊字符自动安全转义），文件面板同步进入该目录
  • 鼠标悬浮条目右侧的 × 可从常用目录中移除
磁盘分析（右侧面板 / 桌面「磁盘」窗口）
  • 输入目录后点搜索（或从 SFTP 工具栏点「分析磁盘占用」），列出每个子目录 / 文件的大小与占比（按大小降序）
  • 点击文件夹逐层下钻找占空间最大的目录，「↑」返回上一级；不跨文件系统挂载点统计
  • 桌面开始菜单「磁盘」会以独立窗口打开同一套分析工具，默认从当前文件目录开始扫描，窗口可拖动 / 缩放 / 最小化，打开后会出现在任务栏窗口区
  • 目录很大时扫描需要等待（面板会显示已用时间），超时可换更小的目录逐层分析
监控与进程
  • 「进程」面板：类任务管理器，支持排序 / 过滤 / 3 秒自动刷新，可结束（SIGTERM）/ 强杀（SIGKILL）；单击进程行查看详情（PID、父进程、用户、状态、CPU、内存、运行时长与完整命令行，支持一键复制）
  • 采样经独立通道读取 /proc，不打扰交互终端；仅支持 Linux 服务器
右上角菜单
  • 连接导入（支持一次框选多个文件，可导入 FinalShell 连接文件）/ 连接导出（弹窗勾选要导出的连接）、字体设置、快捷键设置、终端背景设置、AI 设置（DeepSeek / 通义千问 / 智谱 GLM / MiniMax / Kimi / OpenAI 等厂商，模型列表实时获取、下拉选择）
数据与安全
  • 连接、密码（AES 加密）、快捷命令与背景图存放于数据目录（分发包为程序目录下 data/），拷贝该目录即可迁移
  • 本工具设计为本机使用，请勿直接暴露到公网
