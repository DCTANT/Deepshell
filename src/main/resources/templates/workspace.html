连接与工作台
  • 右上角「＋」打开已保存连接，或点击「新建连接」直接创建后立即连接；连接右侧 ⚙ 可设置置顶 / 收藏 / 编辑连接，也可以把连接拖动到文件夹上快速归入文件夹；文件夹上右键「连接所有」可批量打开其中（含子文件夹）的全部服务器
  • 页面刷新（F5）后会自动恢复之前打开的会话标签并重新连接，不会丢失工作现场
  • 标签：拖动可排序；右键支持复制 IP / 系统信息 / 重新连接 / 断开 / 关闭（其他、左边、右边、全部）；中键点击快速关闭
  • 终端顶栏实时显示远端 CPU / 内存 / 网络利用率，悬浮查看主机、负载与运行时长
命令输入栏（终端底部）
  • 双击 Ctrl 显示 / 隐藏；Esc 关闭；Enter 发送
  • Tab 智能补全（路径 / 历史 / 快捷命令）；Alt 或 ↑↓ 调出历史命令
  • AI 生成命令：点击魔法棒图标展开 AI 输入框，用自然语言描述需求，自动翻译为 shell 命令并填入命令框（需先在右上角菜单「AI 设置」配置 API Key）
  • 右侧工具：历史、选项（发送后清空 / 追加回车 / 忽略空行）、多会话下发（一条命令同时发到多台）、复制 / 粘贴、搜索、连接编辑、全屏
AI 终端（右侧面板）
  • 用自然语言描述需求，AI 会以当前会话的登录用户身份在服务器上自动执行命令、读取输出并逐步推进，直到任务完成；命令与输出以卡片形式展示（含退出码，可复制）
  • 命令走独立通道执行，不干扰（也不显示在）你正在操作的终端；AI 会记住自己 cd 到的目录，但 export 的环境变量不保留
  • 默认「自动执行」：AI 连续执行多步；遇到删除 / 格式化 / 重启等高风险命令会先暂停，在你点击「执行 / 跳过」后继续。切到「每步确认」则每条命令都需你点执行
  • 命令必须是非交互的：不能执行 vi / top 这类需要人工输入的程序；sudo 若无免密会失败；单条命令最长 120 秒，输出过长自动截断
  • 多对话：面板左侧是对话列表（最近使用的在前），点「新对话」开新会话，点条目切换；每个对话有独立上下文与工作目录，鼠标悬浮条目可删除；记录保存在服务端 SQLite 数据库（随数据目录迁移 / 备份），刷新、换浏览器打开都还在（浏览器里旧存的记录首次打开自动迁移入库）
文件 SFTP（右侧面板）
  • 双击目录进入 / 双击文件在线编辑；点击列头排序（名称 / 大小 / 修改时间）
  • 拖动文件名到文件夹即可移动（拖到表格边缘自动滚动找目标，移动前弹确认框）
  • VSCode 图标：下载到本机用 VSCode 打开，保存后自动同步回服务器
  • 工具栏：返回上一目录 / 上级目录 / 新建文件夹 / 新建文件（创建后直接打开编辑）/ 上传 / 刷新当前目录 / 分析磁盘占用 / 目录跟随开
  • 目录跟随（默认开启）：终端里 cd 到某个目录后，文件面板自动切换到该目录；手动浏览不受影响，直到下次 cd；点工具栏链接图标可开关
  • 把系统里的文件直接拖进浏览器窗口即可上传到当前目录（拖入时会显示目标目录提示，成功后顶部弹出提示）
  • 每行操作：下载、重命名、删除（目录递归删除，带确认）
常用目录（右侧面板）
  • 把常用路径存成快捷入口：浏览到目标目录后点「定位」按钮一键添加，或直接输入路径
  • 点击条目即在终端执行 cd（特殊字符自动安全转义），文件面板同步进入该目录
  • 鼠标悬浮条目右侧的 × 可从常用目录中移除
磁盘分析（右侧面板「磁盘」）
  • 输入目录后点搜索（或从 SFTP 工具栏点「分析磁盘占用」），列出每个子目录 / 文件的大小与占比（按大小降序）
  • 点击文件夹逐层下钻找占空间最大的目录，「↑」返回上一级；不跨文件系统挂载点统计
  • 目录很大时扫描需要等待（面板会显示已用时间），超时可换更小的目录逐层分析
监控与进程
  • 「进程」面板：类任务管理器，支持排序 / 过滤 / 3 秒自动刷新，可结束（SIGTERM）/ 强杀（SIGKILL）；单击进程行查看详情（PID、父进程、用户、状态、CPU、内存、运行时长与完整命令行，支持一键复制）
  • 采样经独立通道读取 /proc，不打扰交互终端；仅支持 Linux 服务器
右上角菜单
  • 连接导入（支持一次框选多个文件，可导入 FinalShell 连接文件）/ 连接导出（弹窗勾选要导出的连接）、字体设置、快捷键设置、背景图片设置、AI 设置（DeepSeek / 通义千问 / 智谱 GLM / MiniMax / Kimi / OpenAI 等厂商，模型列表实时获取、下拉选择）
数据与安全
  • 连接、密码（AES 加密）、快捷命令与背景图存放于数据目录（分发包为程序目录下 data/），拷贝该目录即可迁移
  • 本工具设计为本机使用，请勿直接暴露到公网
